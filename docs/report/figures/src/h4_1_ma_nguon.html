calibration, holdout, live; không đưa vào git

đường ống Python

intake.py nhận tệp tải lên vào vùng tiếp nhận
ingest.py nạp Bronze tăng dần theo mã băm
quality_gate.py cửa chặn chất lượng đầu vào

publish.py đưa Gold, ops sang PostgreSQL, đối soát số dòng
